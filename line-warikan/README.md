# LINE 割り勘 Bot（運用コスト 0 円）

LINE で `1200 スーパー` のように送るだけで、生活費スプレッドシート「食費と生活費」に自動で記録され、
てん 2/3・あおい 1/3 の精算額を返信してくれる Bot です。

```
あなた : 3000 食べ物 オーケー
Bot    : ✅ 記録しました（2026/10）
         10/5 てん 3,000円 [食べ物] オーケー

         合計支出: 83,440円
         てん: 支払 83,440 / 負担 55,627
         あおい: 支払 0 / 負担 27,813
         👉 あおい → てん に 27,813円
```

## しくみと費用

```
LINE アプリ ──(Webhook)──▶ Google Apps Script ──▶ Google スプレッドシート
            ◀──(応答メッセージ)──
```

| 使うもの | 料金 |
| --- | --- |
| Google Apps Script（スプレッドシートに付けるスクリプト） | 無料（個人の Google アカウントの無料枠で十分） |
| LINE 公式アカウント「コミュニケーションプラン」+ Messaging API | 無料 |
| Bot からの返信（Reply API） | 無料・送信数の上限にカウントされない |

Bot は届いたメッセージへの「応答」しか送らない（自分から送るプッシュメッセージは使わない）ので、
月 200 通の無料枠も消費しません。サーバーも不要です。

## スプレッドシートへの書き込みルール

今のシートの使い方に合わせています。

- 記録先は日付の月のシート（`2026/10` のような名前。`10月` という名前のシートがあればそれも使う）
- その月のシートが無ければ `template` をコピーして `2026/11` のように自動作成し、`template` のすぐ右に置く
  （template の家賃の行もそのまま引き継がれます）
- A〜E 列の最後の行の次に `日付(日) / 金額 / 誰が払ったか / 何の費用？ / コメント` を書く
- G 列以降のメモ（「あおいが全額払った」など）や集計の式には触らない
- 精算額は、シートの集計欄（合計支出・支払額・負担する額・精算額）の値をそのまま読んで返信する
  → 割合を変えたいときはシートの式を変えるだけで Bot の返信も変わる

## 使い方（LINE に送る言葉）

| 送る言葉 | 動き |
| --- | --- |
| `1200 スーパー` | 自分が払った 1,200 円として記録（`スーパー` は自動で「食べ物」） |
| `1200 日用品 ニトリ` | カテゴリ付きで記録（カテゴリはシートのプルダウンの選択肢） |
| `スーパー 1,200円` / `1200スーパー` | 順番やスペースはゆるくて OK。全角数字も OK |
| `あおい 800 薬局` | 相手が払った分を代わりに記録 |
| `9/28 5250 ガソリン` / `昨日 500 パン` / `3日 300 コープ` | 日付を指定（先月の日付なら先月のシートへ） |
| `-500 返品` | マイナスの金額（返金など） |
| `精算` | 今月の合計と精算額 |
| `精算 9月` / `精算 先月` / `精算 2026/9` | 過去の月の精算額 |
| `履歴` | 今月の最近 5 件 |
| `取消` | 自分が最後に記録した 1 件を取り消す |
| `ヘルプ` | 使い方 |

カテゴリを書かなかったときは「何の費用？」は空欄になります（今のシートと同じ）。
`ガソリン` `家賃` `電気` `薬局` などの言葉はカテゴリが自動で付き、言葉はコメントにも残ります
（対応表は `Code.gs` の `CATEGORY_ALIASES`）。

## セットアップ（15 分くらい）

### 1. LINE 公式アカウントと Messaging API を用意する

1. [LINE Official Account Manager](https://manager.line.biz/) で LINE 公式アカウントを作成（プランは無料の「コミュニケーションプラン」）
2. 作ったアカウントの「設定」→「Messaging API」→「Messaging API を利用する」で有効化（プロバイダーは新規作成で OK）
3. 「設定」→「応答設定」で
   - 応答メッセージ: **オフ**
   - Webhook: **オン**
4. [LINE Developers コンソール](https://developers.line.biz/console/) で同じチャネルを開き、
   「Messaging API 設定」タブの一番下で **チャネルアクセストークン（長期）** を発行してコピー

### 2. スプレッドシートにスクリプトを入れる

1. スプレッドシート「食費と生活費」を開き、メニューの「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を全部消して、このフォルダの [`Code.gs`](./Code.gs) の中身を貼り付けて保存
3. 左の歯車「プロジェクトの設定」で
   - タイムゾーンを「(GMT+09:00) 東京」にする
   - 下の「スクリプト プロパティ」に追加: プロパティ `LINE_CHANNEL_ACCESS_TOKEN`、値 = 1-4 でコピーしたトークン
4. エディタに戻り、上の関数選択で `setup` を選んで「実行」
   - Google アカウントの承認画面が出るので許可（「このアプリは確認されていません」→「詳細」→「（安全ではないページ）に移動」）
   - 実行ログに `?token=xxxxxxxx` と表示されるのでコピー

### 3. Web アプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
2. 「デプロイ」を押して表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

### 4. LINE に Webhook URL を登録する

1. LINE Developers コンソールの「Messaging API 設定」→「Webhook URL」に
   `ウェブアプリの URL` + `?token=xxxxxxxx`（2-4 の文字列）をつなげて貼り付けて更新
   - 例: `https://script.google.com/macros/s/AKfy.../exec?token=0123abcd...`
2. 「Webhook の利用」をオン
3. 「検証」ボタンはエラーになることがありますが（Apps Script はリダイレクトを返すため）、実際のメッセージは届くので次へ進んで OK

### 5. 2 人で友だち追加して登録

1. 「Messaging API 設定」にある QR コードを 2 人とも読み取って友だち追加
2. それぞれのトークで 1 回だけ送る
   - てんのスマホから: `登録 てん`
   - あおいのスマホから: `登録 あおい`
3. あとは `1200 スーパー` のように送るだけ

> 各自が Bot と 1 対 1 でトークするのがおすすめです。2 人と Bot のグループに入れても動きますが、
> グループでは「1000円くらいかな」のような金額を含む普通の会話も記録されてしまうことがあります（`取消` で戻せます）。

## 困ったとき

- **返信が来ない**: Apps Script の左メニュー「実行数」でエラーを確認。Webhook URL の `?token=` が合っているか、
  LINE 側で応答メッセージがオフ・Webhook がオンになっているか確認
- **コードを書き換えた**: 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
  こうすると URL が変わらないので LINE 側の設定はそのままで OK（「新しいデプロイ」を作ると URL が変わります）
- **スマホを変えた／登録を間違えた**: エディタで `resetUsers` を実行してから、もう一度 `登録 てん` などを送る
- **メンバー名や割合を変えたい**: 名前は `Code.gs` の `CONFIG.MEMBERS`、割合はシート（template）の `I5` `I6` の式を変更

## セキュリティについて

Apps Script では LINE の署名ヘッダー（`X-Line-Signature`）を読めないため、代わりに
Webhook URL に付けた推測できない合言葉（`WEBHOOK_TOKEN`）で LINE からのリクエストかを確認しています。
また、記録できるのは `登録` 済みの 2 人だけで、1 つの名前は 1 つの LINE アカウントにしか登録できません。
Webhook URL は他の人に教えないでください。
